# X Surfaces Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Generalize the two-phase image pass into ONE typed asset pass (content + surface lanes) so generated texture lands on page structure via core background supports, cover attributes, and global styles — born on-palette, deduplicated into a per-site dictionary, applied in one drift-refusing transaction, and measured by a pixel-sampling contrast oracle.

**Architecture:** The existing conveyor (scan → generate → manifest → apply → recompile → verify) is extended, never forked. `scan.ts` returns typed refs; the manifest gains `schema_version: 2` with surface entries (one file, many targets); `wp_images_generate`/`wp_images_apply` keep their names and two-phase contract; S8 deterministically mints `metadata.surfaceIntent` markers from the brief's new `surfaces[]` dictionary (same precedent as placeholder minting and nav-link injection); the oracle's `overImage` skip is replaced with clip-screenshot pixel sampling; the companion tokens route gains ONE addition (`styles.background`).

**Tech Stack:** TypeScript (x-agent/mcp, vitest), plain ESM .mjs (pipeline, node:test), PHP (x-companion, bootstrap-lite runner), Playwright canvas 2D for post-processing (no new npm deps).

**Spec:** `specs/surfaces.spec.json` (amends `specs/pipeline.spec.json` and `specs/agent-plugin.spec.json`; on conflict outside the sanctioned changes, base specs win).

## Global Constraints

- The flat band is the reservation AND the fallback: no new placeholder route, no minted surface pixel; failures ship the flat band + a LOUD report entry.
- Never a `data:` URI in tree attributes; never texture via custom CSS/stylesheet/border-image. A surface is a media-library attachment on a core support or global styles, or it does not exist.
- Every surface prompt carries the exact hexes of the bands it touches + the run's one style line. A surface prompt without hexes is a bug.
- One group, one layer: skin + edge = nested groups, never a multi-image mechanism.
- Texture under text only behind the pixel-sampled ink audit (M5 lands in this same PR, so the gate exists before the capability ships).
- Texture-cue-none styles → EMPTY dictionary → correct, complete, green run.
- Capability probed, never assumed: S2 reads the live manifest; missing `core/group` background support degrades group-skin surfaces to none, loudly, in the report.
- No model-side alpha, no model-side seamlessness: mirror-tile and chroma-key are deterministic canvas post-processing.
- Budget: `I = C + U`; only births metered; applications free; ceiling formula otherwise unchanged.
- `--no-images` skips the WHOLE asset pass (both lanes).
- Determinism: no `Math.random()`, no wall-clock in artifact content; identical input bytes → identical processed bytes.
- Repo house rules: pipeline is deps-free ESM on node:test; no ajv; x-agent/mcp `dist/` is committed and the pipeline imports it — every TS change requires `npm run build` + committing dist; 4-space indent; `ghe` not `gh`.

### Task 5: Deterministic processing station (M4)

**Files:**
- Create: `x-agent/mcp/src/images/process.ts`
- Test: `x-agent/tests/images-process.test.ts` (launches chromium; `describe.skipIf` when launch fails)

**Interfaces:**
```ts
export function computeKeyHex(paletteHexes: string[]): string;  // pure: candidate set = RGB cube corners + #00b140 + #ff00ff; pick max of min-distance to palette
export interface ProcessResult { bytes: Buffer; mime_type: string; post_processing: string; lum_min: number; lum_max: number; }
export async function processAsset(page: import('playwright').Page, input: Buffer, inputMime: string,
    opts: { class: 'field'|'pattern'|'frieze'|'spot'|'canvas'; key_hex?: string }): Promise<ProcessResult>;
```
- All canvas work in ONE `page.evaluate` per asset: bytes cross as base64 data: URL; decode via `Image` → `drawImage`.
  - pattern → mirror-tile 2×2 (draw normal, scale(-1,1), scale(1,-1), scale(-1,-1)) → JPEG q=0.85
  - spot → `getImageData`, alpha=0 where RGB distance to key_hex ≤ 48 (hard threshold, no feathering — determinism first) → PNG
  - field/frieze/canvas → recompress JPEG (field/canvas q=0.80, frieze q=0.85)
  - all classes: luminance range = min/max relative luminance over every 4th pixel (stride 4 for wall-clock; deterministic)
- No randomness, no timestamps; identical input bytes → identical output bytes.

**Steps:**
- [ ] Failing tests: mirror-tile output width/height = 2×input; **byte-assert** row equality: for output `y`, pixels `[0..w)` equal mirrored pixels `[2w-1..w]` (decode via a second canvas readback in the same test); chroma-key: a generated 8×8 test PNG (built in-test via canvas) with key-color ground knocks out to alpha 0 and composites over two band hexes without key-color fringes; determinism: two `processAsset` runs over identical bytes produce identical Buffers; `computeKeyHex(['#ffffff', '#f5f0e8', '#333333'])` returns a candidate far from all three and is stable.
